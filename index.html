Pipeline Architecture

How CompGraphRAG Works

A four-stage retrieval-to-determination pipeline that bridges knowledge graphs, symbolic rules, and statistical uncertainty into auditable compliance outputs.

01
🔍

Hybrid Retrieval Scoring

Scores candidate graph nodes using dense bi-encoder cosine similarity, graph-path decay (λ=0.85), and Personalized PageRank authority. Weighted as α=0.40, β=0.50, γ=0.10.

score(x|q) = α·cos(q,x) + β·Path(q→x) + γ·PPR(x)
Dense Bi-Encoder Graph Path Decay PageRank Auth
02
⚖

Neuro-Symbolic Rule Engine

Applies declarative HIPAA rules (45 CFR 164.502, 164.506, 164.312) against retrieved subgraph paths before generation. Prevents hallucination on BAA, TPO, and Minimum Necessary obligations.

RuleEval(π) = {r ∈ ℜ | Conditions(r) satisfied in π}
45 CFR 164.502(e) BAA Gateway TPO Exception
03
📊

Conformal Uncertainty Quantification

Provides distribution-free prediction sets C(q) with guaranteed 90% marginal coverage (α=0.10). Non-conformity scores: 1 − P(y|x). Ambiguous queries route to human audit automatically.

C(q) = {y : s(x,y) ≤ q̂}, Coverage ≥ 1−α = 90%
Split Conformal 90% Coverage Human Routing
04
📄

Audit Certificate Generation

Outputs a traversable justification subgraph (π), natural-language path walk, conformal confidence set, triggered rule IDs, and a machine-readable JSON audit certificate for regulatory verification.

Output: (d, c, π) where d ∈ {COMPLIANT, NON-COMPLIANT, REVIEW}
Subgraph π NL Explanation JSON Certificate

System Design

Architecture Deep-Dive

A layered, audit-grade system combining TBox ontology, hybrid graph retrieval, and conformal statistical guarantees.

HIPAA TBox Ontology Formalization

The knowledge graph is grounded in a formal TBox (terminological box) ontology encoding HIPAA class hierarchies, object property relations, and temporal data-type attributes. This enables structured, machine-verifiable reasoning over regulatory obligations.

FormatOWL 2 / JSON-LD
ClassesRegulation, Rule, Obligation, Role, DataType, Exception, Incident
PropertiesdisclosesPHITo, lacksAgreement, subjectToException, governedBy, satisfiesStandard
TemporaleffectiveDate, regulationVersion, supersededBy (owl:ObjectProperty)
TBox Class Hierarchy
:Regulation --> :Rule (45 CFR 164.502, 164.506, 164.312)
:Rule       --> :Obligation (BAA Required, Min Necessary)
:Obligation --> :Role (CoveredEntity, BusinessAssociate)
:Role       --> :DataType (PHI, DeIdentifiedPHI)
:Obligation --> :Exception (TPOException, IRB_Waiver)
:Incident   --> :DataType

Hybrid Retrieval Scoring

The core scoring function is a convex combination of three complementary signals. Dense similarity captures semantic proximity; graph path score rewards regulatory chain coherence with hop-decay; authority ensures primary regulatory sources rank highest.

ParameterValueRole
α0.40Dense cosine weight
β0.50Graph path weight
γ0.10Authority (PPR) weight
λ0.85Hop decay factor
max_hops4Graph traversal depth
Scoring Formula
score(x | q) =
  alpha * cos(q_emb, x_emb)        // Dense semantic
  + beta * GraphPathScore(q, x)    // Graph path decay
  + gamma * Authority(x)           // Personalized PageRank

GraphPathScore(q_ent, path) =
  (1/|path|) * sum( w_r * conf(u,r,v) * lambda^(h-1) )

// w_r   = TBox relation weight in [0,1]
// conf  = triple extraction confidence in [0,1]
// lambda= 0.85 hop decay (penalizes distant hops)
// h     = 1-indexed hop distance

Split Conformal Prediction

Distribution-free prediction sets with guaranteed marginal coverage. Calibration split (12 queries) computes non-conformity scores; quantile q-hat set at the correct level; test-time sets include any class below threshold.

alpha (risk)0.10
Coverage1−alpha = 90%
Non-conformitys(x,y) = 1 − P(y|x)
Cal split12 queries
Human routing|C(q)|≥2 or REQUIRES-REVIEW∈C(q)
Conformal Algorithm
// 1. Compute calibration non-conformity scores:
s_i = 1.0 - P(y_i | x_i)  for i in cal_set

// 2. Set quantile threshold:
q_hat = quantile(s_1..s_n, ceil((n+1)*(1-alpha)/n))

// 3. Build prediction set:
C(q) = { y : s(x,y) <= q_hat }

// 4. Human routing logic:
if |C(q)| == 1 and 'REQUIRES-REVIEW' not in C(q):
  is_unambiguous = True
  requires_human_review = False
else:
  requires_human_review = True  // -> Human Auditor

HIPAA Neuro-Symbolic Rule Engine

Declarative first-order logic rules evaluate retrieved subgraph paths before LLM generation. Symbolic gating prevents hallucination on mandatory obligations and correctly handles carve-out exceptions.

RULE-BAA-REQUIRED§164.502(e)
RULE-TPO-EXCEPTION§164.506
RULE-MIN-NECESSARY§164.514
RULE-TECH-SAFEGUARD§164.312
Rule Definitions
// BAA Requirement (45 CFR 164.502(e)):
IF (Recipient in BusinessAssociate)
   AND (BAA_Document not in pi)
   THEN FLAG_NON_COMPLIANT

// TPO Exception (45 CFR 164.506):
IF (Purpose in {Treatment, Payment, Operations})
   AND (TPO_Exception in pi)
   THEN FLAG_COMPLIANT_EXCEPTION

// Min-Necessary (45 CFR 164.514(d)):
IF (MinNecessary_Obligation in pi)
   AND (AccessScope == 'full_record')
   THEN FLAG_REVIEW

// Technical Safeguards (45 CFR 164.312):
IF (DataType == UnencryptedPHI)
   AND (Network in {PublicWiFi, Unprotected})
   THEN FLAG_NON_COMPLIANT

Primary Hypothesis
H4/H8 Scaling

Knowledge Graph Hop-Scaling Relationship

The marginal accuracy gain of KG-augmented retrieval over dense vector RAG scales directly with query hop distance — a measurable, testable H4/H8 hypothesis about graph-based reasoning advantage on multi-hop compliance queries.

H4/H8 Benefit = Acc(CompGraphRAG, k-hop) − Acc(VectorRAG, k-hop)
Novel Contribution

Audit-Grade Explainability

Quantitative faithfulness evaluation (Precision, Recall, F1) measuring whether generated explanations match true retrieved subgraph edges in path π — a first for HIPAA compliance determination systems.

F1 = 97.98% on 24-query test set
Statistical Guarantee

Distribution-Free Uncertainty

Split conformal prediction applied to compliance determination, providing rigorous finite-sample coverage guarantees independent of model assumptions, validated via paired t-test and Wilcoxon signed-rank tests.

p-value validated · Holm-Bonferroni corrected

Important Disclosure & Limitations

System outputs are produced by a research prototype operating on a synthetic HIPAA-based dataset. They must not serve as the sole legal basis for regulatory liability determination without human reviewer verification. Entity linker precision is 21.9% (broad-recall-first strategy). External baselines (GraphRAG, LightRAG, HippoRAG) are flagged as NOT MEASURED as those repositories are not locally installed. Accuracy on the 12-query test split: CompGraphRAG 70.8%, Vector-RAG 79.2%, Naive-RAG 83.3%.
