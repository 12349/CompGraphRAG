COMPGRAPHRAG // OPERATOR & ARCHITECTURE SYSTEM GUIDE
Welcome to the CompGraphRAG Compliance Control Suite. This guide explains how to use the interactive audit workbench and how the underlying research pipeline operates.
1. Quickstart — How to Run an Audit (4 Steps)

Step 1: Select Query Scenario — Choose from preset 1-hop, 2-hop, or 3-hop HIPAA regulatory queries (e.g. BAA disclosure §164.502(e), IRB research waiver §164.506).

Step 2: Click Execute Pipeline — Triggers the 4-stage retrieval and reasoning sequence.

Step 3: Inspect Traversed Subgraph π — Review the interactive graph canvas displaying retrieved node entities (Role, Obligation, Exception, DataType) and edge relations (`disclosesPHITo`, `lacksAgreement`, `subjectToException`).

Step 4: Verify Conformal Set & Export JSON — Review the final determination (`PASS`, `FLAGGED`, `WARN`), conformal confidence set $C(q)$, and click EXPORT.JSON for auditor verification.

2. Architecture & Pipeline Stages Explained

[01] Hybrid Retrieval Scorer: Calculates $\text{score}(x|q) = \alpha \cdot \cos(q_{\text{emb}}, x_{\text{emb}}) + \beta \cdot \text{GraphPathScore}(q_{\text{ent}}, \text{path}_x) + \gamma \cdot \text{Authority}(x)$ with hop-decay factor $\lambda = 0.85$.

[02] Neuro-Symbolic Rule Check: Evaluates candidate subgraphs against 45 CFR rules prior to generation, surfacing required BAA nodes or TPO exception carve-outs.

[03] Split Conformal Uncertainty: Generates distribution-free confidence sets $C(q)$ guaranteed at target coverage level $1 - \alpha = 90\%$. Low confidence sets route to human audit.

[04] Audit Certificate Generation: Outputs traversable subgraph paths $\pi$ and exportable machine JSON payloads.

3. Benchmark Metrics Key

Hop-Scaling Marginal Benefit (H4/H8): Measures the percentage improvement of CompGraphRAG over vector RAG as query complexity increases from 1-hop to 3-hops (+50% F1 gain).

Explanation Faithfulness F1: Precision and Recall evaluating whether generated explanations match true retrieved edges in subgraph $\pi$.

Expected Calibration Error (ECE): Quantifies calibration error between model confidence and actual determination accuracy.
